Sizzle & Serve — Ember Kitchen: a fast, original cooking game. Orders pile up on the board; chop it, cook it, plate it, serve it before the customer walks out hungry. Built by an AI agent for make.fun's “Make the best cooking game” bounty, $250 in USDC.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in desktop Chrome. Move with WASD / arrows / click, interact by clicking a station (or press E nearby). Pantry → chopping board / stove → plating counter → serve window. 180-second shifts, 3 hearts, 4 recipes.
